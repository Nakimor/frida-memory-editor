# 🧠 Frida GG GUI

GUI-редактор памяти на базе [Frida](https://frida.re) — аналог **Cheat Engine** / **GameGuardian** с поддержкой Android (через USB) и локальных процессов на ПК.

Позволяет сканировать память запущенного процесса, находить и изменять значения (HP, монеты, патроны и т.д.), замораживать их и сохранять готовые «читы» в виде таблицы для повторного использования.

> 🇷🇺 README на русском языке. English version: [`README.en.md`](README.en.md).

---

## ✨ Возможности

- 🔍 **Точный поиск** — поиск конкретного значения по всей доступной памяти (`rw-` регионы).
- ❓ **Поиск неизвестного значения** — снимок всех чисел в ограниченной области памяти (~8 МБ) с последующим сужением через фильтры «Изменилось» / «Не изменилось» / «Больше» / «Меньше» / «Между».
- 🧮 **Типы данных**: `byte`, `int16`, `int32`, `int64`, `float`, `double`, `string` (ASCII).
- 📌 **Список наблюдения (Cheat Table)** — отдельная таблица для избранных адресов с именами, независимая от результатов текущего скана.
- ❄️ **Заморозка значений** — как всех найденных адресов разом, так и по отдельности в списке наблюдения.
- 💾 **Сохранение / загрузка таблиц** — экспорт и импорт списка наблюдения в формате JSON.
- 📱💻 **Два режима подключения** — Android-устройство через USB и локальный процесс на ПК.
- ⚡ **Attach и Spawn** — подключение к уже запущенному процессу или запуск приложения самой Frida с внедрением скрипта до старта.
- ✏️ **Редактирование прямо в таблице** — двойной клик по найденному адресу или записи в списке наблюдения.
- 🎨 **Тёмная розовая тема**, вкладки, всплывающие подсказки по каждому режиму поиска, прокручиваемый интерфейс (не обрезается на маленьких экранах).

## 📋 Требования

- **Python 3.7+**
- Пакеты:
  ```
  pip install frida frida-tools
  ```
- Для работы с **Android**:
  - Root-доступ на устройстве
  - Включённая отладка по USB
  - [`frida-server`](https://github.com/frida/frida/releases), скопированный на устройство (версия должна совпадать с версией пакета `frida` на ПК)
  - Установленный `adb` в системе

## 🚀 Установка и запуск

### 1. Установка зависимостей на ПК

```bash
pip install frida frida-tools
```

### 2. Запуск frida-server на Android-устройстве

```bash
adb push frida-server /data/local/tmp/
adb shell "chmod 755 /data/local/tmp/frida-server"
adb shell "su -c /data/local/tmp/frida-server &"
```

Проверить, что всё запущено:

```bash
frida-ps -U
```

Если в списке видны процессы устройства — всё работает.

### 3. Запуск скрипта

```bash
python frida_gg_guiclaude.py
```

Для локального режима (ПК) `frida-server` не требуется — используется собственный процесс Frida.

## 📖 Краткая инструкция по использованию

### Подключение

В блоке **«1. Подключение»** выберите режим:

- **📱 USB (Android)** — список запущенных приложений подтягивается автоматически, можно фильтровать по названию.
- **💻 Локальный (PC)** — список процессов текущего компьютера.

Есть два способа подключиться:

1. **⚡ Подключиться (Attach)** — выберите процесс из списка и нажмите кнопку. Подходит для уже запущенных приложений.
2. **🚀 Spawn-запуск** — введите идентификатор пакета (например, `com.example.app`) или путь к исполняемому файлу и нажмите «Запустить и внедриться». Frida сама запустит процесс и внедрит скрипт до первой инструкции — полезно, если Attach выдаёт ошибку вроде `ptrace pokedata`.

### Поиск значения

1. Выберите **тип данных** (диапазон значений для каждого типа показан прямо под выбором).
2. Введите известное значение (например, текущее количество патронов) и нажмите **🔍 Первый поиск**.
3. Измените значение в приложении (например, выстрелите) и сузьте список одним из фильтров: **Равно / Не равно / Больше / Меньше / Изменилось / Не изменилось / Между**.
4. Повторяйте шаги 2–3, пока не останется 1–2 адреса.

Если исходное значение неизвестно — используйте **❓ Неизвестное значение**: сначала снимается срез всех чисел в памяти, затем список сужается теми же фильтрами (например, «Изменилось» после любого действия в приложении).

### Изменение и заморозка

- **Двойной клик** по найденному адресу — редактирование значения на месте.
- **✏️ Записать во все** — записать новое значение сразу во все найденные адреса.
- **❄️ ЗАМОРОЗИТЬ ВСЕ** — периодически перезаписывать все найденные адреса заданным значением (например, бесконечное здоровье).
- Правый клик по адресу → **📌 Добавить в список наблюдения** — закрепить конкретный адрес отдельно от результатов поиска.

### Список наблюдения (Cheat Table)

На вкладке **📌 Список наблюдения**:

- Добавление адресов вручную или из результатов поиска.
- Индивидуальная заморозка каждой записи (не всей таблицы разом).
- Переименование записей для удобства.
- **💾 Сохранить таблицу / 📂 Загрузить таблицу** — работа с готовыми наборами читов в формате JSON через меню «Файл».
